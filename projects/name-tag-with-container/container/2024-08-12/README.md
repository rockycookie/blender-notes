# Notes
In this print, I tried using
- build plate adhension type: `Raft`

which prints a layer of basement, and then print the actual object on that basement.

It did not work well for my 200 dolors 3D printer, as the bottom surface of the actual object has a lower resolution comparing to other faces.

To make it worse, after tearing the actual object apart from the basement layer, there were small threads left on the edges of the bottom face.

## My suggestion for future
Just keep using
- build plate adhension type: `Brim`
